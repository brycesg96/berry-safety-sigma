# Consolidado corporativo de inspecciones

La descarga de Gestión de Inspecciones respeta los filtros del panel. El archivo usa los datos textuales ya autorizados del panel; no consulta ni incorpora fotografías o firmas gráficas y no modifica inspecciones ni envía correos.

El formato incluye siete hojas:

| Hoja | Contenido |
| --- | --- |
| Resumen | Periodo, fecha de generación en Lima, indicadores, estados, riesgos, filtros aplicados y enlaces a las demás hojas. |
| Inspecciones | Registro, fecha, hora, sede, zona, gerencia, área, abreviatura, instalación, ubicación completa, inspector, estado y avance. |
| Fichas | Empleador, RUC, datos de referencia, tipo y detalle, objetivo, causas, conclusiones, fechas y referencias anteriores. Cada inspección empieza en una página nueva al imprimir. |
| Observaciones | Descripción, riesgo, medida propuesta, plazo, estado, decisión y atraso por observación. |
| Seguimiento | Responsable, persona que registró el avance, acción realizada, fecha, estado propuesto, decisión y comentario del revisor. |
| Participantes | Personas y roles de inspección, área y registro, correos, gerencias, áreas, abreviaturas, puestos y fechas del registro. |
| Notificaciones | Destinatarios Para, emisor incluido, copias históricas Responde a (CC), fechas y último resultado del servicio. |

Las tablas tienen encabezados en la fila 6, filtros, las primeras dos columnas y seis filas fijas, fechas numéricas y porcentajes, bandas alternadas y colores de estado. La impresión repite las columnas de identificación y los encabezados. El resumen está preparado para A4 y las tablas para A3 horizontal en hasta dos páginas de ancho. No se convierte una aceptación del servicio de correo en confirmación de entrega o lectura.

Los nombres y ubicaciones históricos proceden del registro, sin reconstruirlos a partir del catálogo actual. Las celdas sin información se mantienen vacías; no se inventan datos de gerencia o puesto para documentos antiguos. Se diferencia el estado ejecutado del levantamiento de su aprobación por el revisor.

Se muestra como imagen sin enlace en la barra superior. La cabecera verde utiliza una tarjeta blanca. El acceso al perfil se conserva en el recuadro lateral del usuario.
